# Security policy

## Supported versions

Until a newer minor release is published, the latest `0.1.x` release receives security fixes. Older
minor lines are unsupported. The exact supported API and platform tiers are defined in the
[stability policy](docs/stability.md).

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's private vulnerability
reporting flow for [bernaferrari/guavakt](https://github.com/bernaferrari/guavakt/security/advisories/new).

Include a minimal reproduction, affected module/version, target platform, impact assessment, and
any suggested mitigation. Reports are acknowledged within seven days; confirmed issues receive a
status update and coordinated-fix plan as soon as triage is complete.

Security fixes are disclosed after a fix or practical mitigation is available. Credit is offered to
reporters who want it.
